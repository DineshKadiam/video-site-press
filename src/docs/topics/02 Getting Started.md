# Getting Started

After having installed Hyper 8, create an empty directory
somewhere on your disk. This will be your *site directory*
that contains all your content. For this guide we'll assume
we created the directory at the path `/users/alice/demo`.

Now open a terminal to start Hyper 8, passing the site directory path.

```
hyper8 /users/alice/demo
```

This will open Hyper 8's web editor in your browser, automatically, and from
there on you can fill and preview your entire site using the browser
interface.

Note however that you can also populate and configure your site by
putting content in your site directory, using solely your file browser
and text editor!

As Hyper 8 is still in an early version, some functionality is only
available via the browser interface, while other functionality is only
available through putting content in the site directory in the file
browser and text editor. It is strongly recommended to read the rest
of the docs (which can be done in just a few minutes anyway) to get
a deeper picture of what is there, and how things work. This will
benefit understanding of the browser interface as well.
