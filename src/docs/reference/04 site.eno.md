# site.eno

Manifest for configuring the site. The site manifest is optional but
when it exists it must be placed at the root of the site directory.

```eno
base_url: https://example.com
theme: dark
```

With `base_url` you configure at which domain your site will be hosted,
which is used for ... (TODO).

The `theme` option can be set to either `dark` or `light`.
