# collection.eno

Manifest for tagging and configuring a collection, that is, a container
for videos, playlists and further subcollections that reside within the
collection.

```eno
poster: my_poster.jpg
title: Awesome clickbaitz videos
unlisted

-- description
New videos are released every tuesday!

Also check us out on the [fediverse](https://social.example.com/)
-- description
```

The `description` field supports markdown.
