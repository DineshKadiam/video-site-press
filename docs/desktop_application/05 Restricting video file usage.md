# Restricting video files to streaming/download/offline usage

For each video file (that you upload or which has finished encoding) you can control how it is used by changing the toggle that initially says `No usage restrictions`:

- `Streaming only` means that even if you enable downloads (which are disabled by default) this video will still only be provided for streaming

- `Download only` means that the video will be provided for download (if you enable downloads for the video), but never for streaming

- `Keep offline` means that the video will not be published at all (this is for instance useful if you want to keep the original, high quality file around, but only want to provide other, smaller versions on your site)
