# Adding video files

In the editor you can upload video files from ...

- a collection page (creates a new video inside the collection)
- a playlist page (creates a new video inside the playlist)
- the `Video/Audio files` subpage of an already existing video

Important: Every video file you add **is automatically used for streaming on your site**
(but this can be changed for each file by [restricting its usage](restricting-video-file-usage.html)).

If a video file you added is ...

- in a browser-compatible format (Hyper 8 will try to detect this for you)
- in a resolution suitable for streaming
- compressed well enough for streaming

... you do not necessarily need to process it further.

If it is lossless, very high resolution, in a browser-incompatible format, or
you simply want to provide additional (e.g. smaller) versions, you can
request resized or re-encoded versions by following the steps described on
the next page.
