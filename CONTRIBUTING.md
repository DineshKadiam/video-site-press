# Contributing

## LLM Policy

This project cherishes human collaboration and learning, personal and
intellectual growth, and above all else, approaches and strategies that
actively work to minimize the harms done to our ecosystem and society through
technology. We find software making practices built on exploitative LLM
systems as they currently permeate the software industry to be fundamentally
incompatible with these values and goals. Please leave your agents and
expensively rented LLM services at the door when you enter this house.
